Первая рабочая версия · Python3.12 · без входной диагностики

Рабочая среда для серьёзной подготовки.

Университетская программа: две основные дисциплины одновременно, самостоятельные задачи, защита и отложенное повторение. Архитектура рассчитана на 26 недель по 36 сосредоточенных часов. Первая неделя готова: четыре урока, задачи и решения, лабораторная, семинары и контроль. Полные уроки всего полугодия ещё не написаны.

1. Открой папку в VS Code

File → Open Folder → папка с course.json. Установи расширения Microsoft Python и Jupyter. Команды ниже выполняй в терминале этой папки после установки Python3.12.

python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m ipykernel install --user --name masters-2027 --display-name "Masters2027"
python course.py environment
python course.py status

2. Проверь установку

Открой notebooks/00_environment.ipynb → Select Kernel → Masters2027 → Run All. Это техническая проверка установки. pending означает, что учебная функция ещё не реализована.

3. Начни первую неделю

Маршрут и комплект → урок A. Markdown можно читать в GitHub или VS Code; локальный HTML курса собирается командой ниже.

Основа программы

Прочитай учебную систему, маршрут и источники. Начальная линия — основания оптимизации по Osborne и экономический выбор. W01 назначается после обучения нужным понятиям. Полный модуль выпускается по docs/UNIT_STANDARD.md.

4. Сдай собственную попытку

python course.py selfcheck
python course.py submit

Первый шаг проверяет расчёты; второй создаёт ZIP снимок для разбора. Письменная часть, предпосылки и устная защита оцениваются отдельно. Присылай архив в чат.

5. Подключи GitHub и Zotero

Порядок: docs/GITHUB.md и docs/ZOTERO.md. Импортируй literature/references.bib в Zotero; аннотации и собственные заметки связывай со страницами. Полные книги не вложены.

Локальный сайт курса

python -m pip install -r requirements-book.txt
jupyter-book build .
open _build/html/index.html

Сайт — оглавление и материалы. Вычисления выполняются в Jupyter. Работа в VS Code доступна без запуска сайта.
