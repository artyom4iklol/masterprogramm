# Masters2027: экономическая теория, финансы и исследование

Начни с [инструкции](../docs/SETUP_MAC.md), затем [первой недели](week01.md).
Система использует длинные задачи, формальные выводы, код и письменную защиту.
Базовые проценты и линейные преобразования доступны как справочные знания;
они не составляют обязательное ядро этой недели.

Первая неделя: KKT → двойственность → спрос факторов → межвременной выбор →
OLS → денежные потоки → данные GaR → письменные и устные ответы.

После чтения [протокола](../docs/WORKFLOW.md) открой [W01](../assignments/week01/W01_KKT.md).
Полугодовая структура — [маршрут](roadmap.md); выполненные работы определяют
объём дальнейших комплектов.
