# Masters2027: учебная программа

Начни с [выбранной системы обучения](LEARNING_SYSTEM.md), затем прочитай [маршрут](roadmap.md) и [реестр источников](../literature/CORE_SOURCES.md). Две основные дисциплины одновременно; 36 часов содержательной работы в неделю; обязательная самостоятельная практика и возвращение к пройденному.

Первая линия — математические основания экономического выбора по Osborne, затем задачи потребителя. Входной диагностики нет. Полный комплект первого нового модуля должен соответствовать [стандарту](../docs/UNIT_STANDARD.md); стандарт не является самим уроком.

[W01–W09](week01.md) — сохранённый банк задач для разных этапов, а не обязательная первая неделя. Среда и проверки уже созданы, полный полугодовой курс уроков ещё не написан.

Для установки используй [инструкцию Mac](../docs/SETUP_MAC.md), для передачи работы — [протокол](../docs/WORKFLOW.md). Вычислительные проверки не заменяют оценку объяснений и доказательств.
