# Masters2027: учебная программа

**Для начала занятий открой [готовую первую неделю](../weeks/week01/README.md).**

Общая программа: [выбранная система обучения](LEARNING_SYSTEM.md), затем прочитай [маршрут](roadmap.md) и [реестр источников](../literature/CORE_SOURCES.md). Две основные дисциплины одновременно; 36 часов содержательной работы в неделю; обязательная самостоятельная практика и возвращение к пройденному.

Первая линия — математические основания экономического выбора по Osborne, затем задачи потребителя. Входной диагностики нет. Полный комплект первой недели подготовлен по [стандарту](../docs/UNIT_STANDARD.md): теория, практика, решения и контроль находятся в `weeks/week01`.

[W01–W09](week01.md) — сохранённый банк задач для разных этапов, а не обязательная первая неделя. Среда и проверки уже созданы, полный полугодовой курс уроков ещё не написан.

Для установки используй [инструкцию Mac](../docs/SETUP_MAC.md), для передачи работы — [протокол](../docs/WORKFLOW.md). Вычислительные проверки не заменяют оценку объяснений и доказательств.
