# Магистратура2027 — рабочая учебная среда

**Первая неделя готова: [открыть комплект на 36 часов](weeks/week01/README.md).** Версия 1.1: начни с практики P1–P3, затем следуй маршруту. До четырёх дополнительных часов предусмотрены только как резерв по правилам комплекта.

Общая основа: [учебная система](course/LEARNING_SYSTEM.md), [маршрут на 26 недель](course/roadmap.md) и [источники](literature/CORE_SOURCES.md).
Технический запуск: `START_HERE.html` и `docs/SETUP_MAC.md`.

Основной формат: университетские источники → разобранные примеры → самостоятельные задачи → защита → отложенная проверка. Бюджет — 36 сосредоточенных часов в неделю, две основные дисциплины одновременно.

Созданы архитектура, рабочие инструменты и полный учебный комплект первой недели: математическая практика P (6 упражнений), четыре урока, 24 основные задачи с решениями, лабораторная, МО/английский/научное чтение, контрольная и отложенные варианты. W01–W09 сохранены как начальный банк задач, распределяемый по этапам; прежние 48 часов не являются обязательным планом первой недели. Полные учебные модули на все 26 недель ещё не написаны. `course.py` отслеживает только девять существующих работ. [Стандарт модуля](docs/UNIT_STANDARD.md) определяет, что должно быть подготовлено до назначения нового урока.
Входной диагностики нет. Ноутбук00 проверяет только установленную среду.

## Первый запуск

Скачай репозиторий через Code → Download ZIP или клонируй его:

```bash
git clone https://github.com/artyom4iklol/masterprogramm.git
cd masterprogramm
```

Открой папку, содержащую `course.json`, через VS Code → File → Open Folder.
В терминале этой папки (Mac):

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m ipykernel install --user --name masters-2027 --display-name "Masters2027"
python course.py environment
python course.py status
```

Нужен установленный Python3.12.x. Если команда `python3.12` не найдена, сначала
установи эту ветку Python по инструкции SETUP_MAC; не меняй команду вслепую на
другой системный Python. В VS Code установи расширения Microsoft Python и Jupyter,
открой `notebooks/00_environment.ipynb`, выбери ядро Masters2027 и выполни Run All.

## Рабочий цикл

1. Назначенное чтение с конкретным вопросом и страницей источника.
2. Самостоятельный письменный вывод в `work/week01/Wxx.md` или приложенный PDF.
3. Реализация функций в `work/week01/answers.py` и эксперименты в ноутбуке.
4. `python course.py selfcheck` — вычислительная часть; статус passed не является зачётом.
5. Запись первой попытки в Git и `python course.py submit` — архив для разбора.
6. Отправка архива в чат: проверка предпосылок, доказательства и интерпретации.
7. Исправление с объяснением причины ошибки; новый снимок; устная защита.
8. Запись фактического разбора через `record-review` по протоколу.

Ответы и код нужно написать самостоятельно: стартовые функции намеренно оставлены
с NotImplementedError. Они не заменяются фиктивными значениями. Проверки доступны
для прозрачности; балл за письменное решение требует отдельного разбора.

## Команды

| Команда | Результат |
|---|---|
| `python course.py environment` | Версии установленных библиотек |
| `python course.py status` | Отдельно история содержательного разбора и состояние кода |
| `python course.py selfcheck` | Проверки задач; failed означает ошибку, pending — незавершённую реализацию |
| `python course.py submit` | ZIP снимок работ и контрольные суммы, журнал сдач |
| `python course.py record-review feedback/W01_review.json` | Запись состоявшегося разбора; шаблон нельзя считать проверкой |

## Оценка

Пять критериев по20: вывод; предпосылки; расчёты; интерпретация;
воспроизводимость. Учебный зачёт требует80/100, отсутствия критической ошибки,
защиты и успешной вычислительной части, если она предусмотрена.
Это критерий этого курса, не официальный проходной балл магистратур.

## Сайт курса — дополнительный слой

Для локального сайта после основного запуска:

```bash

open _build/html/index.html
```

ветка Jupyter Book 1.0.4.post1 для локальной сборки Sphinx без облачного API.
Это сознательно выбранная версия, а не заявление о последнем релизе.
Сборка не исполняет незаполненные ноутбуки; расчёты выполняй в VS Code/Jupyter.
Браузер может загружать внешние ресурсы темы при просмотре.
Работать по заданиям в VS Code можно и без запуска сайта.
