# Проверка поставки

Проверено 13 октября 2026 года. Проверка программной инфраструктуры не является
оценкой учащегося или гарантией поступления.

## Выполнено

- Структура: девять заданий, пять ноутбуков, 48 плановых часов первой недели.
- Синтаксис Python и JSON; схема nbformat всех пяти ноутбуков; пути оглавления.
- Все 17 кодовых ячеек последовательно исполнены в каждом из двух состояний:
  незаполненный комплект и внутренние эталонные реализации. Для каждого ноутбука
  использован новый процесс Python с IPython InteractiveShell — всего 34 запуска ячеек.
- Шесть групп вычислительных проверок прошли на эталонных реализациях:
  KKT, двойственность, фирма, OLS, денежные потоки и горизонт роста GDP.
- В стартовом комплекте шесть групп корректно показывают pending; решения оставлены
  незаполненными. Эталоны не входят в репозиторий, оценки учащегося не выставлены.
- Проверены ZIP снимок сдачи, SHA-256, метаданные и включение приложенного PDF.
- Незавершённый код не получил зачёт даже при 100 баллах в тестовом протоколе;
  заполненный код и записанный разбор дали ожидаемый результат в изолированной копии.
- Намеренно неверный налог на ликвидационный доход обнаружен финансовой проверкой.
- Импорт FRED-формата проверен на искусственных CSV: квартальное среднее NFCI,
  число недель, соединение с GDP и паспорт происхождения. Это не загрузка и
  не исследование настоящих данных США.
- Локальная HTML сборка Jupyter Book 1.0.4.post1/Sphinx завершилась успешно.
  Учебные ноутбуки при сборке не исполняются.

## Что ещё проверяется на твоём компьютере

Среда подготовки не позволила запустить транспорт настоящего Jupyter-ядра:
системное ограничение сетевых интерфейсов привело к завершению libzmq.
Исполнение ячеек в отдельном процессе проверяет код, но не заменяет проверку
интеграции VS Code, ядра и отображения графиков на Mac. Выполни Run All в
notebooks/00_environment.ipynb после выбора .venv/Masters2027.

Основной комплект рассчитан на Python 3.12. Зависимости расчётов закреплены в
requirements.txt; версии Jupyter имеют ограниченные диапазоны. После установки
сохрани фактическое окружение через pip freeze по инструкции SETUP_MAC.

## Границы поставки

Первая неделя содержит задания; для следующих 25 недель пока задан маршрут.
Закрытые учебники и их полные главы не вложены. Библиографические назначения
связаны с первоисточниками; статус доступа указан в literature/SOURCES.md.
Требования приёма 2027 года и индивидуальные форматы экзаменов требуют отдельной
сверки с опубликованными документами вузов.

Зелёный GitHub Actions не является учебным зачётом: pending намеренно разрешён.
Публикация сайта GitHub Pages не настроена. Содержательный разбор начинается
после получения собственной попытки учащегося.

## Выбор сборщика

Сборка Jupyter Book 2 была отклонена автоматической проверкой: она обращалась
к внешнему mystmd API, а состав передаваемых материалов/метаданных не был установлен.
Поэтому используется локальный Sphinx-сборщик Jupyter Book 1.0.4.post1. Ветка
закреплена осознанно; её не следует считать последним релизом Jupyter Book.


## Пересмотр учебной архитектуры 13 октября 2026

Новая система и маршрут заменяют обязательную первую неделю из девяти работ. Подготовлены реестр источников и стандарт модуля; они честно разделяют прочитанный текст, проверенную библиографию и ещё не написанные уроки. Программный манифест сохраняет 48 исходных часов банка задач и не является календарём новой программы. В W01 уточнено значение shadow на вырожденной границе m=0: правая производная функции ценности; множество допустимых KKT-множителей рассматривается отдельно. Вычислительная логика проверок не менялась.

После пересмотра прошли проверка целостности пакета и локальная сборка Jupyter Book 1/Sphinx. Эти проверки подтверждают структуру файлов и сборку, а не результативность обучения.
