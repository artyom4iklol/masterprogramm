# Реальные CSV для GaR

Открой https://fred.stlouisfed.org/series/GDPC1 и
https://fred.stlouisfed.org/series/NFCI. Download→CSV; выбери исходные уровни,
без редактирования единиц/частоты через график. Сохрани GDPC1.csv,NFCI.csv
в data/raw. Пропиши точный источник,дату загрузки и диапазон в data_provenance.md.

```bash
python tools/import_real_data.py --gdp data/raw/GDPC1.csv --nfci data/raw/NFCI.csv
```

Скрипт принимает DATE или observation_date; колонки GDPC1,NFCI.
Он усредняет доступные недельные значения по календарным кварталам, сохраняет
число недель и SHA256 исходных файлов. Он не обрезает неполные кварталы молча:
список кварталов с количеством значений<10 записывается в provenance.json.
Порог10 — технический сигнал для проверки, не утверждённая методика исследования.
Выбери и обоснуй собственное правило после просмотра календаря ряда.

GDP должен быть положительным, иметь одну строку на квартал и не иметь
пропущенных кварталов. Пропуски и дубли требуют решения по данным, а не ffill.
Дата квартала не означает дату публикации. Текущие пересмотренные ряды подходят
для первичной сборки, но не заменяют данные, доступные при историческом прогнозе.
Только после этого вызывай свою growth_targets в notebook04.
