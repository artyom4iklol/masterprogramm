# Репозиторий masterprogramm

Проект: https://github.com/artyom4iklol/masterprogramm. Подробная инструкция для занятий — [HOW_TO_STUDY.md](HOW_TO_STUDY.md).

## Получить рабочую копию

В терминале из выбранной папки:

```bash
git clone https://github.com/artyom4iklol/masterprogramm.git
cd masterprogramm
git switch -c study/week01
```

Открой папку целиком в VS Code. Если репозиторий уже клонирован, не создавай вторую копию без необходимости. Если ветка существует, `git switch study/week01`. Альтернатива без Git — Code → Download ZIP; commit/push в распакованном архиве не работают.

## Сохранить первую попытку

Заполняй work/first_week/submission.md и сохраняй дополнительные решения/сканы рядом. После блока P1–P3:

```bash
git add work/first_week
git commit -m "Week 1: P1-P3 first attempt"
git push -u origin study/week01
```

Исправления — отдельная попытка или отдельный commit с объяснением причины. Не нужно изменять учебные тексты, чтобы записать свой ответ. Лабораторную скопируй в work/first_week перед редактированием.

После push пришли в чат ссылку на файл в своей ветке или commit, версию недели и фактическое время. Доступ к репозиторию не означает автоматический разбор новых изменений. Можно вместо Git прикрепить свои файлы/сканы в чат. Токены в файлы курса не записываются; для push используется обычный вход GitHub в VS Code.

## Обновить материалы

Сначала сохрани и закоммить собственные изменения, затем в study/week01:

```bash
git fetch origin
git merge origin/main
```

При конфликте сохрани работы и пришли сообщение для разбора. После успешного merge команда `git push` отправляет обновлённую учебную ветку. Для ZIP новая версия скачивается отдельно, после чего свои работы переносятся из старой папки.

## Что означают проверки

GitHub Actions проверяет инфраструктуру и математические ключи. Зелёный результат не является твоим учебным зачётом. `course.py status`, `selfcheck` и `record-review` обслуживают прежний банк W01–W09; новая неделя P/A–D оценивается по сохранённым работам, защите и отложенным попыткам.

Публикация GitHub Pages пока не настроена. Материалы доступны в GitHub и локально в VS Code, расчёты — в Python/Jupyter. Локальный HTML можно собрать по README, но для начала занятий это не требуется.
