# Научная библиотека в Zotero

1. Установи Zotero и Connector по https://www.zotero.org/download/.
2. Создай коллекцию Masters2027 и подколлекции Micro, Macro, Econometrics,
Finance, IR, GaR.
3. Импортируй literature/references.bib. Указанный учебник и назначенная статья
не считаются прочитанными после импорта библиографии.
4. Прикрепи законно доступные PDF. Сохраняй страницу источника, версию и DOI.
5. Для каждого источника используй research/paper_passport.md: вопрос,
переменные, метод, данные, результат, ограничения, страницы, вопросы к автору.
6. Аннотации переносишь в заметки со ссылками на страницы. Для диплома нужен
сам текст и проверяемая ссылка, не только автоматически составленное резюме.

Обзор20–30 статей собирается постепенно. Неделя1 требует одного рабочего
первоисточника по GaR и назначенного фрагмента по МО.
PDF не включены в репозиторий; в пакете находятся ссылки и библиографические записи.
Инструкции Zotero: https://www.zotero.org/support/pdf_reader
