# W02. Маршаллианский/хиксианский спрос, двойственность, Слуцкий ·7 часов

U=x^α y^(1−α),0<α<1; px,py,m>0. Область потребления неотрицательна.

1. Выведи маршаллианский спрос x(p,m),y(p,m), докажи внутренний глобальный оптимум.
2. Выведи косвенную полезность v(p,m); проверь однородность степени0 по(p,m).
3. Реши минимум px·x+py·y при U≥u,u>0. Выведи e(p,u) и хиксианские спросы.
4. Проверь двойственность e(p,v(p,m))=m и h(p,v(p,m))=x(p,m).
5. Выведи, а затем проверь тождества Роя и Шепарда; явно назови переменные,
которые фиксируются в каждой производной.
6. Из связи h(p,u)=x(p,e(p,u)) получи дифференциальное уравнение Слуцкого.
7. Для α=1/2,px=2,py=1,m=12 составь матрицу компенсированных ценовых эффектов:
симметрия, отрицательная полуопределённость, нулевое направление цен.
8. Цена x повышается до4. Найди новую корзину; компенсацию Хикса для исходной
полезности; компенсацию Слуцкого для исходной корзины. Разложи конечное
изменение x обоими способами и объясни различие с дифференциальной формулой.
9. Численно проверь Шепарда и однородность при α=0,3 и0,7; после этого объясни,
какие проверки являются математическими свойствами, а не эмпирическим доказательством модели.

Реализовать marshallian,expenditure,hicksian; формат результатов в answers.py.
Цены/доход/полезность должны быть положительны,α строго между0 и1; иначе ValueError.
