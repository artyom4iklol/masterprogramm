# W01. KKT, углы и насыщение ·5 часов

Максимизировать U(x,y)=8x+6y−(x²+y²)/2 при x≥0,y≥0,2x+y≤m; m≥0.
Это собственная учебная модель, где полезность не монотонна на всём первом квадранте.

1. Докажи существование и единственность оптимума для каждого конечного m.
2. Выпиши KKT с выбранной конвенцией знаков. Не забывай множители неотрицательности.
3. Найди весь параметрический ответ x*(m),y*(m) и допустимые множители бюджета, включая границы режимов. При m=0 отдельно исследуй единственность множителя: единственность оптимальной корзины сама по себе её не гарантирует.
4. Проверь каждый режим: допустимость, знаки множителей, stationarity,
complementarity. Объясни случаи активного ограничения с нулевым множителем.
5. Получи оптимальное значение v(m), его производную на режимах и её связь с λ.
Для m=0 интерпретируй правую производную отдельно.
6. Построй графики x*,y* и предельной ценности бюджета v′(m), используя правую производную при m=0, для0≤m≤30. При m=1,12,24 отметь корзины и остаток бюджета.
7. Измени коэффициент цены x с2 на3: выведи новые границы до запуска кода.
8. Объясни, почему механическое равенство расходов доходу исключило бы часть решений.

Реализация: consumer_quadratic(m) в answers.py для исходных цен. Возвращает
dict с ключами x,y,shadow. Поле shadow означает предельную ценность v′(m); при m=0 — правую производную v′₊(0), а не произвольно выбранный множитель из множества KKT. Отрицательный/неконечный доход→ValueError.
Чтение: MIT14.04 Lecture2; Nicholson/Snyder гл.3–4; Kreps AppendixA.
Код дополняет письменный вывод; аналитические режимы обязательно получить вручную.
